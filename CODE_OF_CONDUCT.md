# Contributor covenant: code of conduct

## Our standard

Everyone contributing to MoEAtlas — issues, reviews, code, docs — is
expected to keep discussions technical, honest, and respectful. In
particular:

- Critique code and evidence, never people.
- Do not misrepresent validation status: model-free contract evidence is
  not checkpoint evidence, and deferred rows stay deferred until run.
- Assume good faith; prefer clarifying questions over accusations.

## Unacceptable behavior

Harassment, discriminatory language, personal attacks, publishing private
information, or bad-faith disruption are unacceptable anywhere the project
is discussed.

## Enforcement

Maintainers may remove, edit, or reject contributions that violate this
document, and may temporarily or permanently ban contributors for repeated
or severe violations. Reports go to the maintainers privately through
GitHub; reports are reviewed confidentially.

## Attribution

This document adapts the Contributor Covenant convention to this
repository's evidence-first working rules.
